# js-template-repository-practice

I made this project to practise creating a GitHub template repository and setting up linting, formatting and bundling for a JavaScript project.

## What's included

- **webpack**: bundles JavaScript, CSS and images from `src/` into `dist/`, with separate development and production configs
- **webpack-dev-server**: local dev server with live reloading
- **ESLint**: catches problems in JavaScript code
- **Prettier**: formats code consistently
- **Husky + lint-staged**: runs ESLint and Prettier on staged files before every commit

## Requirements

- Node.js 20.11 or later

## Getting started

1. Click **Use this template** on GitHub to create a new repository, then clone it.
2. Install dependencies:

   ```
   npm install
   ```

   This also sets up the Husky pre-commit hook.

3. Update `name` and `description` in `package.json` for the new project.

## Scripts

| Command          | What it does                                           |
| ---------------- | ------------------------------------------------------ |
| `npm run dev`    | Starts the dev server and opens the app in the browser |
| `npm run build`  | Creates a minified production build in `dist/`         |
| `npm run lint`   | Checks all JavaScript files with ESLint                |
| `npm run format` | Formats all files with Prettier                        |

## Project structure

```
src/
  index.js          Entry point
  styles.css        Styles, imported in index.js
  template.html     HTML template used to generate dist/index.html
webpack.common.js   Shared webpack config
webpack.dev.js      Development config (dev server, eval source maps)
webpack.prod.js     Production config (minified, separate source maps)
eslint.config.mjs   ESLint config
.prettierrc         Prettier config
```

## Notes

- `dist/` is generated by the build and is not committed.
- `.gitattributes` forces LF line endings, so Prettier doesn't flag files on Windows.
- `eslint-config-prettier` turns off ESLint rules that would clash with Prettier.
